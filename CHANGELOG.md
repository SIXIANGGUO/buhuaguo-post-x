# Changelog

## 1.58.0 - 2026-03-29

### Features

- Initial standalone release of `buhuaguo-post-x`
- Clipboard-first workflow for regular posts, quote posts, video posts, and X Articles
- Rich-text article preparation for pasting into the X Article editor
- Automatic download of remote article images into a local cache
- Short helper commands such as `./xa-next` and `./xa-cover` for fast manual image insertion
- Markdown table rendering to local PNG files so tables remain usable in X Articles
