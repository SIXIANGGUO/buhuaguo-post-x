# Launch Copy

## X / Twitter Post

Built and open-sourced `buhuaguo-post-x`.

It is a clipboard-first skill for posting to X:
- prepare rich-text X Articles
- download remote article images locally
- turn Markdown tables into PNG files for X Article compatibility
- insert images with short commands like `./xa-next`

Repo:
https://github.com/SIXIANGGUO/buhuaguo-post-x

## 中文版发布文案

我把自己现在在用的 X 发布辅助 skill 开源出来了：`buhuaguo-post-x`

它不是去自动控制 X 网页，而是把发布流程拆成更稳的手工工作流：
- 正文先整理好并复制到剪贴板
- 远程图片自动落地到本地
- Markdown 表格自动转成 PNG，适配 X Article
- 插图时直接用 `./xa-next`、`./xa-cover` 这种短命令

项目地址：
https://github.com/SIXIANGGUO/buhuaguo-post-x

## 朋友圈 / 长一点的中文版

最近把我自己写的一套 X 发布辅助工具整理成了独立项目，名字叫 `buhuaguo-post-x`。

这套工具的思路不是“自动点网页按钮”，而是把内容准备做扎实，把真正发布留给人工完成，所以会稳很多。

它现在能做的事情包括：
- 把 Markdown 文章整理成更适合粘贴进 X Article 的富文本
- 把远程图片自动下载到本地
- 把 Markdown 表格自动转成图片，解决 X Article 不吃表格的问题
- 自动生成 `./xa-next`、`./xa-cover` 这种短命令，让插图过程轻很多

如果你也会写长文、发 X Article，可能会觉得这套流程挺顺手。

项目地址：
https://github.com/SIXIANGGUO/buhuaguo-post-x
